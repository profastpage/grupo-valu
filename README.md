# GRUPO VALU — Solución Financiera de Confianza

Plataforma web oficial de **GRUPO VALU** (RUC: 20616559363), especializada en préstamos personales al instante y créditos con garantía vehicular en todo el Perú.

![GRUPO VALU Open Graph](public/og-image.jpg)

---

## 🚀 Características Principales

- **Préstamos Personales al Instante:** Aprobación rápida en menos de 24 horas hábiles con montos desde S/ 500 hasta S/ 20,000.
- **Garantía Vehicular:** Financiamiento de hasta S/ 100,000 sin dejar de usar tu auto, respaldado por alianza estratégica con **Procustodia**.
- **Calculadora Financiera Dinámica:** Simulación en tiempo real de cuotas mensuales según el monto y plazo elegido.
- **Libro de Reclamaciones Virtual:** Cumplimiento total del Código de Protección y Defensa del Consumidor (Ley N° 29571) de la República del Perú.
- **Diseño Ultra-Luxury Inmersivo:**
  - Lienzo obsidian dark con acentos en oro metálico y plata platino.
  - Menú de navegación flotante: **100% transparente** en el hero principal para máxima inmersión, con transición dinámica a **crema perlado elegante** (*pearl cream luxury*) al hacer scroll.
  - Menú desplegable móvil optimizado con soporte para drawer lateral táctil.
- **SEO & Open Graph Avanzado:** Previsualizaciones completas y atractivas para WhatsApp, Facebook, Twitter/X y LinkedIn con tarjetas oficiales de alta definición (1200x630 px).

## 🛠️ Stack Tecnológico

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animaciones:** [Framer Motion](https://www.framer.com/motion/)
- **Iconografía:** [Lucide Icons](https://lucide.dev/)

## 📦 Instalación y Desarrollo Local

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Disponible en [http://localhost:3005](http://localhost:3005).

3. **Compilar para producción:**
   ```bash
   npm run build
   ```

4. **Ejecutar en producción:**
   ```bash
   npm start
   ```
